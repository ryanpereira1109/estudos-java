# ☕ Estudos e Exercícios em Java & SQL

Repositório dedicado à prática diária e consolidação de fundamentos de lógica de programação, Orientação a Objetos e Banco de Dados Relacional.

## 📁 Estrutura de Pastas

- **`fundamentos-logica/`**: Variáveis, estruturas condicionais (`if/else`), laços de repetição (`for/while`) e vetores/arrays.
- **`orientacao-a-objetos/`**: Modelação de classes, encapsulamento, herança, polimorfismo e interfaces.
- **`banco-de-dados-sql/`**: Criação de tabelas, inserção de dados e consultas com `JOIN` em SQL.

## 🛠️ Tecnologias e Ferramentas
- **Linguagem:** Java (JDK 17+)
- **Banco de Dados:** SQL 
- **Versionamento:** Git & GitHub
